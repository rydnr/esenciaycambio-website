# Sistema Profesional Esencia & Cambio

**Nombre:** Sistema Profesional Esencia & Cambio.

**Finalidad:** base de conocimiento viva para la gestión, práctica clínica y desarrollo de la consulta.

Este repositorio no debe almacenar datos identificativos de pacientes ni documentación clínica real. Cualquier material clínico incluido debe ser genérico, anonimizado y no identificativo.
